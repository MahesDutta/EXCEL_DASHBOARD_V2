# Excel Intelligence Dashboard v2

A browser-only Excel business intelligence dashboard built with React, Vite, SheetJS and Recharts.

## Included
- XLSX, XLS and CSV upload
- Automatic header-row detection
- Header normalization and duplicate-header protection
- Automatic date/number/text type detection
- Automatic KPI selection
- Large responsive charts
- Dynamic filters based on workbook columns
- Date range and quick ranges
- Search across all columns
- Automatic local business insights
- Exact-value KPI and tooltip formatting
- Cleaned Excel export
- Filtered CSV export
- Print / Save as PDF through the browser
- Multi-sheet workbook support
- Light/dark mode
- No backend and no API key

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

For GitHub Pages, set Settings -> Pages -> Source to GitHub Actions.
